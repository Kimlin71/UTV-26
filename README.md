# My MiniProjects in the C# training

### Notes
This project was created during the first week of C# training.
Some files in this repository are instructor reference examples used to explain concepts. My own projects are listed below.

## 1. Product List Manager

A simple C# console application created as a beginner-level mini project.

### Description
This project allows the user to manage a list of product names through a simple console menu. The program continues until the user chooses Exit.

### Features
- Input product names from the console
- Add and validate product names
- View products in alphabetical order
- Search for a product
- Delete a product
- Display basic statistics

### This project was built to practice:
- C# basics
- user input
- loops and conditions
- arrays and lists
- validation
- sorting data in C#
- methods and switch statements

## 2. Product List Manager System

A simple C# console application created as a beginner-level mini project.

### Description
This project allows the user to manage a list of products through a simple console menu. Each product has a category, a name, and a price. The program continues until the user chooses Quit, and typing `q` at any prompt returns to the menu immediately.

### Features
- Add products with category, name, and price
- Validate all user input
- Search for products by name or category
- View all products sorted by price (lowest first)
- Display the total value of all products
- Cancel any operation by typing `q`

### This project was built to practice:
- C# basics
- User input and validation
- Loops and conditions
- Lists and objects
- Methods and switch statements
- LINQ (`OrderBy`, `Where`, `Sum`)
- Exception handling for control flow

### Technologies
- C# (.NET 10)
- Console Application
- Visual Studio Code (Mac)
